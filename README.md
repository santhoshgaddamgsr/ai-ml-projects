## 1️⃣ LLM Reasoning Agent (LangGraph + RAG)

📁 `llm-reasoning-agent-langgraph/`

An enterprise-style LLM reasoning system capable of:

* Intelligent routing between RAG and direct LLM
* LangGraph-based agent orchestration
* FAISS vector retrieval
* Retrieval confidence scoring
* Explainable decision making
* DeepEval-based evaluation framework
* Vertex AI / Gemini integration
* Docker + Cloud Run compatibility

Includes:

* Full evaluation framework with threshold validation
* Faithfulness, Answer Relevancy, Context Precision metrics
* Evaluation history tracking

This project demonstrates advanced reasoning workflows and measurable AI system quality.

## 2️⃣ Local AI Coding Agent (Qwen 7B + Ollama)

📁 `local-qwen-coder-7b-agent/`

A fully local AI-powered coding assistant built using open-source LLMs.

Capabilities:

* Code generation
* Bug fixing
* Code review
* Multiple agent modes (generate / fix / review)
* GPU-accelerated local inference via Ollama
* FastAPI backend with browser-based UI

Architecture demonstrates:

* Local LLM deployment without external APIs
* Agent-oriented prompt design
* Backend–LLM integration patterns
* Full-stack AI application development

This project highlights practical engineering for running AI systems fully offline with controllable infrastructure, privacy, and cost efficiency.
